# Kalai's Fashion Store — React

A responsive single-page fashion storefront inspired by the supplied design.

## Run locally

1. Install Node.js (LTS).
2. Extract this project and open the folder in VS Code.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Included
- Responsive navigation and mobile menu
- Search products by name
- Category filters
- Product cards with prices
- Favorite heart buttons
- Add-to-cart count and confirmation toast
- Responsive layout for desktop, tablet, and mobile

## Notes
- Product photos are loaded from Unsplash, so an internet connection is needed to display them.
- Login is a UI placeholder. Connect it to your authentication backend when ready.
- This is a frontend demo; cart data is stored only in React state and resets on refresh.
